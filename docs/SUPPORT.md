# Remote Bitaxe / AxeOS Support

I help Bitaxe users flash and stabilize their miners without guesswork.

## What I Can Help With

- `Firmware and AxeOS versions do not match`
- wrong or missing `www.bin`
- wrong or missing `esp-miner.bin`
- pool fallback warnings
- high ping
- stale shares
- high error rate
- unstable hashrate after flashing
- BM1366, BM1368, and BM1370 configuration review
- safer firmware sharing notes for friends

## What To Send

Open an issue or send a message with:

- Bitaxe model and ASIC chip
- screenshot of the AxeOS dashboard
- firmware version
- AxeOS version
- pool URL and worker format
- ping shown in the dashboard
- stale share percentage
- error rate
- temperature and hashrate after 10 minutes of running
