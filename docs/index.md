# Bitaxe Flash Doctor

Remote Bitaxe / AxeOS support and offline firmware bundle checks.

## Get Help

If your Bitaxe shows a firmware / AxeOS mismatch warning, fallback pool warning, high ping, stale shares, high error rate, or unstable hashrate after flashing, open a support request:

[Open Bitaxe Support Request](https://github.com/0xjc65eth/bitaxe-flash-doctor/issues/new?template=bitaxe-support.yml)

## What I Help With

- matching `esp-miner.bin` and `www.bin`
- firmware / AxeOS version mismatch
- pool setup review
- ping, stale shares, and error rate
- BM1366, BM1368, and BM1370 setup review
- safer firmware sharing checklists
