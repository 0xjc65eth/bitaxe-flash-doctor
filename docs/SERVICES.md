# Bitaxe / AxeOS Remote Support

Remote help for Bitaxe miners who need a clean flash, a stable dashboard, or a second pair of eyes before sharing firmware with friends.

## What I Fix

- firmware / AxeOS mismatch warnings
- mixed `esp-miner.bin` and `www.bin` versions
- pool fallback warnings
- high ping
- stale shares
- high error rate
- unstable hashrate after flashing
- BM1366, BM1368, and BM1370 configuration review
- flash checklist and bundle verification before sharing files

## Support Packages

### Quick Flash Review

Best for checking a firmware bundle before flashing.

- verify file roles
- check SHA-256 hashes
- inspect version strings
- confirm both firmware and AxeOS assets are present
- produce a short flash checklist

Payment: BTC tip or agreed amount before starting.

### Dashboard Health Check

Best after flashing when AxeOS shows warnings or bad mining numbers.

- review dashboard screenshot
- check firmware / AxeOS mismatch
- review pool URL and worker format
- look at ping, stale shares, error rate, temperature, and hashrate
- suggest conservative next steps

Payment: agreed before starting.

### Group Flash Checklist

Best when sending firmware to friends, a mining group, or a small fleet.

- create manifest
- create `SHA256SUMS`
- write a clean flash note
- document expected firmware and AxeOS versions
- list common mistakes to avoid

Payment: agreed before starting.
